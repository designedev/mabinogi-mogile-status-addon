# mStatusBar

마비노기 모바일의 상태를 Windows 작업 표시줄에 표시하는 독립 애드온입니다. 웹 서버나 브라우저 없이 게임에 포함된 CLI와 직접 연결합니다.

## 지원 스킬셋

| 기능 | 사용 방법 | 사용하는 CLI 명령 |
| --- | --- | --- |
| 현재 행동 | 이동·전투·채집·연주 등 현재 상태 표시 | `get_activity` |
| 에린 날씨·시간 | 행동 옆에 날씨 아이콘과 에린 시각 표시 | `get_current_environment` |
| 캐릭터 HP | 왼쪽 핑크색 세로 바와 HP 툴팁, 사망 시 붉은색 깜빡임 | `get_my_info`, `get_activity` |
| 제작 작업 | 통합 버튼에서 진행·완료 목록 확인, 완료품 수령 | `get_altering_works`, `complete_altering_work` |
| 악보 연주 | 음악 영역에서 보유 악보 선택 후 즉시 연주 | `get_music_scores`, `play_music_score` |
| 주변 연주 | 내 연주가 없을 때 가까운 플레이어의 곡명 표시 | `get_near_pcs` |
| 연결 확인 | 연결 테스트와 자동 재연결 | `status`, `capabilities` |

상태 조회는 기본 2초 간격이며 설정에서 1~60초로 변경할 수 있습니다. 음악 시간·진행 막대는 조회 사이에도 갱신됩니다. 주변 연주는 게임이 제공하는 플레이어 상태를 사용하며 실제 소리를 분석하지 않습니다.

## 시작하기

Windows 11 24H2 이상(빌드 26100 이상)과 마비노기 모바일 PC 클라이언트가 필요합니다. 소스에서 실행 파일을 만들려면 [빌드 안내](docs/DEVELOPMENT.md)를 참고하세요. 자체 포함 배포본은 .NET을 따로 설치하지 않아도 됩니다.

1. 게임을 실행하고 **환경 설정 → 게임 → 마비노기 모바일 AI 커넥터 기능**을 켭니다.
2. `mStatusBar.exe`를 실행합니다. 처음 실행하면 설정 화면이 열립니다.
3. **찾아보기**에서 게임에 포함된 `MabinogiMobile_CLI.exe`를 선택합니다.
4. **연결 테스트**가 성공하면 조회 주기와 표시 위치를 지정하고 **저장 및 적용**을 누릅니다.

이후 설정은 **애드온 우클릭 → 설정** 또는 트레이 아이콘에서 엽니다. 설정은 `%LOCALAPPDATA%\mStatusBar\settings.json`에 저장됩니다.

## 화면 사용법

- **HP 바**: 아래에서 위로 현재/최대 HP 비율을 표시합니다. 마우스를 올리면 수치와 비율을 확인할 수 있습니다. 사망 상태가 확인되면 붉게 깜빡이고 부활하면 멈춥니다.
- **날씨·시간**: 날씨 아이콘과 에린 시각 `HH:mm`을 표시합니다. 마우스를 올리면 날씨 원문을 확인할 수 있습니다.
- **행동 영역·제작 버튼**: 음악 카드와 제작 진행·완료 목록을 엽니다. **수령하기**는 선택한 품목의 시설로 이동해 그 시설의 완료품을 모두 수령합니다.
- **음악 영역·음악 카드 제목**: 보유 악보를 가나다순으로 표시합니다. 악보를 선택하면 바로 연주합니다. 별도의 재화 소모 확인 없이 실행되므로 선택 전에 곡을 확인하세요.
- **팝업 닫기**: 바깥 클릭, `Esc`, 같은 영역 재클릭으로 닫습니다. 진행 중인 수령·연주는 팝업을 닫아도 계속됩니다.
- **종료·재연결**: 애드온 우클릭 또는 트레이 메뉴를 사용합니다.

수령에 승인이 필요한 게임 스키마가 제공되면 확인창을 표시합니다. 지원하지 않거나 조회에 실패한 날씨·HP는 빈 상태로 표시합니다. 연결이 끊기면 오래된 정보를 비우고 자동으로 다시 연결합니다.

## 표시 설정

- **위치**: 오른쪽 알림 영역 앞, 가운데, 왼쪽 끝, 시작 버튼 앞, 자동 중 선택합니다. 가운데는 오른쪽 빈 영역 안에서 화면 중앙에 가깝게 배치해 시작 버튼·앱 아이콘과 겹치지 않게 합니다. Windows 작업 표시줄이 왼쪽 정렬이면 왼쪽 끝·시작 버튼 앞은 오른쪽으로 대체됩니다.
- **음악 효과**: 이퀄라이저, 물결, 숨쉬는 점, 궤도, 효과 없음을 선택합니다. 재생 시간 또는 남은 시간을 표시할 수 있습니다.
- **배경**: 색상과 투명도 0~100%를 지정합니다. 글자와 버튼은 선명하게 유지합니다.
- **Windows 자동 실행**: 켜고 저장하면 현재 사용자 로그인 시 실행합니다. 실행 파일을 옮긴 경우 새 위치에서 다시 저장하세요.

작업 표시줄 공간이 부족하면 표시 폭이 줄어들 수 있습니다. CLI 경로가 바뀌거나 게임 연결에 실패하면 설정에서 파일과 게임의 AI 커넥터 활성화를 확인하세요.
